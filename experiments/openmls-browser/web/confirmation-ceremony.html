양쪽 기기 암호화 확인

초대 교환이 끝난 보관함에서 상대 기기의 암호문을 검증하고 확인 응답을 보냅니다. 각 기기는 자신이 검증하고 저장한 결과만 표시합니다. 기기 등록과 대화 활성화는 별도입니다.

초대 교환을 마친 보관함을 여세요. 관리자가 이 격리 시험 단계를 별도로 연 뒤 사용합니다. 확인을 시작한 보관함은 이 화면에서 다시 여세요.

선택한 역할의 실제 보관함 이름을 입력하세요. 새 키를 만드는 화면은 아닙니다.

결과 확인은 저장된 같은 확인 정보를 다시 보낼 수 있습니다. 자동 전송이나 자동 재시도는 하지 않습니다.

인계 요청 대조

요청을 읽은 뒤 별도 경로로 받은 확인값과 대조하세요.





현재 격리 시험은 32~128자의 생성된 시험 비밀번호를 사용합니다.




중단되거나 결과가 확인되지 않은 작업이 있습니다. 같은 보관함과 요청으로 확인하세요.
계정·보관함·요청·작업을 직접 선택하세요.
