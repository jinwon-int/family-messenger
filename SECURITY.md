# Security policy

The native server and encryption/device experiments are synthetic-data-only prototypes.
They are not approved for real family conversations or public network deployment.
See [the server boundaries](server/README.md) before running them.

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/jinwon-int/family-messenger/security/advisories/new).
Include the affected commit, a minimal synthetic reproduction, impact and expected behavior.
Do not include live credentials, family messages, attachments or recovery keys.
If private reporting is unavailable, do not put exploit details or private data in a public issue;
wait until the repository's private reporting channel is available.

Security fixes are developed against the default branch. There are no supported production
releases or guaranteed response times yet. Third-party components retain their own security policies.
