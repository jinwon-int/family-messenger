# agent-choices-v1 — 에이전트 선택지 탭 선택 (family-messenger#620)

에이전트와 일하다 보면 답의 끝이 거의 늘 같다: 조사·구현 결과 뒤에 `1. … 2. … 3. …` 선택지를 주고
「권장: N번」을 붙여 묻는다. 사용자는 `1` 을 입력해 답한다. 한데는 이런 선택지를 **눌러서 체크하고
[보내기]** 로 고를 수 있게 그린다. 보내는 것은 지금 손으로 치는 것과 **똑같은 텍스트 `N`** 이다 —
봇·브리지·릴레이·와이어는 바뀌지 않고, 텍스트로 답하는 길도 그대로다(iOS 승인 카드 `승인 n` 과 같은 결).

와이어를 늘리지 않는 이유: 브리지 → 봇 `result` 프레임에 필드를 더해도 봇은 `status`·`text` 만 방으로
올린다(`bot/src/responder.rs`). 구조화 선택지는 봇·릴레이·앱 3층 규격 변경이라 이 기능의 범위 밖이다.

## 1. 판정 (세 앱 공통 — 공유 벡터 `tests/fixtures/agent-choices-vectors.json`)

입력은 **에이전트가 보낸 텍스트 메시지 본문** 하나. 정규식의 숫자는 ASCII `0-9` 만, `\s`·공백은 스페이스·탭·줄바꿈으로 본다(플랫폼 간 차이를 없애려고 — 전각 `１` 은 숫자가 아니다). 출력은 `null` 또는
`{ items: [{ number, label }], recommended: number | null }`.

1. 줄 나누기: `\r\n` → `\n` 후 `\n` 으로 나눈다.
2. 코드 펜스: 왼쪽 공백을 뺀 줄이 ```` ``` ```` 로 시작하면 펜스를 열고/닫는다. 펜스 줄과 그 안의 줄은
   **항목이 될 수 없는 일반 줄**이다.
3. 항목 줄(펜스 밖): 정규식 `^ {0,3}([0-9]{1,2})[.)][ \t]+(\S.*)$`. 번호 = 첫 묶음(10진수).
4. 블록 만들기 — 위에서 아래로 한 번 훑는다:
   - 번호 `1` 항목 줄 → **새 블록 시작**(이전 블록은 버린다).
   - 열린 블록이 있고 번호 = 마지막 번호 + 1 → 블록에 추가.
   - 그 밖의 번호 항목 줄 → 지금 후보 블록을 **무효**로 만든다(열려 있든 닫혀 있든; 뒤에 `1` 이 오면 다시 시작).
   - 빈 줄(공백뿐) → 블록 상태 그대로.
   - 들여쓴 줄(공백 2칸 이상 또는 탭으로 시작) → 열린 블록이 있으면 마지막 항목의 이어지는 줄(라벨엔 넣지 않는다).
   - 그 밖의 줄(펜스 줄 포함) → 블록을 **닫는다**(닫힌 블록은 후보로 남지만 더 붙지 않는다).
   훑기가 끝났을 때 마지막으로 시작된 블록이 후보다(무효가 됐으면 결과 `null`).
5. 후보 조건 — 모두 만족해야 선택지:
   - 항목 수 2~9.
   - 블록이 끝난 뒤(마지막 항목 줄 + 이어지는 줄 다음)의 **비어 있지 않은 줄이 3줄 이하**.
   - 단서(cue)가 있다: 블록 첫 항목 바로 위의 비어 있지 않은 줄, 블록 뒤 줄들, 항목 라벨 중 하나에
     아래 문자열이 들어 있다(영문은 대소문자 무시):
     `?` `？` `권장` `선택` `골라` `고르` `답해` `원하시` `할까요` `하시겠` `정해` `다음 액션` `다음 단계` `옵션`
     `choose` `option` `recommend`
6. 라벨: 항목 줄의 마커 뒤 글(위 정규식 둘째 묶음)에서 `**`·`__`·`` ` `` 를 지우고, 연속 공백을 한 칸으로,
   양끝 공백 제거.
7. 권장 번호(`recommended`):
   1. 메시지 전체(펜스 포함)에서 `권장\s*[:：]?\s*([0-9]{1,2})\s*번` 첫 일치의 숫자가 1..k 이면 그 번호.
   2. 아니면 라벨에 `권장` 이 든 첫 항목 번호.
   3. 아니면 `null`.

## 2. 상태 (타임라인에서 계산 — 저장하지 않는다)

선택지가 있는 에이전트 메시지 M 에 대해, M **뒤**의 저장된 메시지(텍스트·첨부; status-v1 임시 줄·시스템 줄 제외)를 본다.

| 상태 | 조건 | 그리기 |
|---|---|---|
| `open` | M 뒤에 메시지가 없다 | 선택 카드(체크 + [보내기]) |
| `answered(N)` | M 바로 다음 메시지가 **내 것**이고 본문(양끝 공백 제거)이 `^([0-9]{1,2})\s*번?\.?$` 이며 N ∈ 1..k | 한 줄 「✓ N번 선택 — 라벨」 |
| `closed` | 그 밖 | 카드 없음(말풍선만) |

「내 것」은 각 앱의 기존 판정(같은 사람의 다른 기기 포함 여부도 기존 규칙)을 그대로 쓴다.

## 3. 화면

- 말풍선 아래 카드. 행 = 체크 원 + `N` + 라벨(최대 3줄) + 권장이면 「권장」 알약.
- 행 탭 = 그 하나만 선택(다시 누르면 해제). 선택이 있을 때만 [보내기] 활성 → 평소 전송 경로로 `"N"` 전송.
  보내는 동안 카드 비활성. 보낸 메시지가 타임라인에 오면 상태 규칙으로 `answered(N)` 가 된다.
- 작성창은 그대로 쓸 수 있다 — 손으로 `2` 를 보내도 같은 `answered(2)` 가 된다.
- 접근성: 행 = 버튼, 라벨 「N번: 라벨」(+ 「권장」), 선택 상태 표시. [보내기] 라벨 「N번 보내기」.
- 웹: AI 참여 동의가 필요한 방에서는 전송이 막히는 기존 규칙(`sendText` false)을 그대로 따른다.

## 4. 범위 밖
