# alert-refs-v1 — 플릿 알림의 `#번호` 를 눌러 원래 알림으로 이동 (오너 요청 2026-11-07)

플릿 알림 봇(`fleet-bot`, actor `fleet`) 글은 모두 **자기 번호**로 시작하고(ccc-node `fleet_alerts_*`),
본문 안에서 다른 알림 번호를 **참조**한다:

```
[서서] #7pdo6k 🧪 테스트 알림 …                      ← 자기 번호 7pdo6k
#69pgri ⏰ 재통지 1/3 #6c9kzj (action, …)              ← 자기 69pgri, 참조 6c9kzj
#a1b2c3 ✅ #7pdo6k ok 접수 11:15 — … · 재통지 중지      ← 자기 a1b2c3, 참조 7pdo6k
```

한데(웹·iOS·Android)는 참조를 링크로 그리고, 누르면 같은 방에서 그 번호로 시작하는 알림으로 이동한다.

## 1. 판정 (세 앱 공통 — 공유 벡터 `tests/fixtures/alert-refs-vectors.json`)

- **번호**: `#` + ASCII 소문자·숫자 정확히 6자(`[0-9a-z]{6}`). 앞 글자가 ASCII 영숫자·`_`·`#` 이면 번호가 아니고(글 처음은 됨),
  뒤 글자가 ASCII 영숫자·`_` 이면 번호가 아니다(글 끝은 됨). 대문자는 번호가 아니다.
- **자기 번호(`self`)**: 글이 `[<라벨>] `(라벨 1~40 유니코드 스칼라(코드 포인트 — 이모지 하나 = 1), `]`·줄바꿈 없음)로 시작하면 그 뒤, 아니면 글 처음에서 바로 번호가 나오고
  그 뒤가 스페이스·줄바꿈·글 끝이면 그 번호. 아니면 `null`.
- **참조(`refs`)**: 글 안의 모든 번호 가운데 자기 번호 자리를 뺀 것, 나온 순서대로(같은 번호가 여러 번이면 여러 번).
  **자기 번호와 같은 번호는 참조가 아니다**(자기 자신으로 가는 링크는 쓸모가 없다).

## 2. 이동

- 대상 = 같은 방의 플릿 알림 봇 글 가운데 `self` 가 그 번호인 **가장 최근(seq 가 가장 큰)** 글. 누른 글 자신은 빼다.
- 있으면 그 말풍선으로 스크롤(가운데)하고, 웹은 잠깐 밝힌다(`jumpToBubble` flash).
- 없으면(아직 안 불러온 옛 글·다이제스트에만 있는 info 알림) 안내 「원래 알림이 이 화면에 없어요」.
- 링크는 **플릿 알림 봇 글에만**. 사람·에이전트·다른 서비스 봇 글의 `#…` 은 그대로 글이다.
- 허용 URL 링크와 겹치는 번호는 URL 링크가 이긴다.
