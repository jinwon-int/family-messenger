# 한데 디자인 시스템 — 1차 (2026-10-31)

원본: Claude Design 「한데앱 및 웹 디자인 개선 – Hande 1차.html」(파일보관함, sha256 `335c9283…`) · 의뢰서 `hande-app-design-brief-20261031.md` · 토큰 정본 [`hande-tokens.json`](hande-tokens.json).

1차 범위 = **토큰 정리(밤·낮불) + 대화 목록(자리) + 대화방·허락 카드(밤·낮불) + 모닥불 용어 적용표**. 2차(전 화면·아이콘), 3차(Android 전 화면·스토어), 4차(웹)는 별도.

## 1. 색 토큰

| 역할 | 밤(기본·고정) | 낮불(e-ink·밝은 곳) |
|---|---|---|
| 배경 위 · 밤하늘 | `#0F1324` 아래로 잉걸불 번짐 | `#F7F3EA` 종이, 단색 |
| 배경 아래 · 불빛 땅 | `#5A2C12` radial 45%→0 | — 없음(그라데이션 금지) |
| 불 · 1차 강조 | `#F59E42` 주 버튼·내 말풍선 | `#D97A1E` 포인트 1색, 허락·보내기만 |
| 진한 불 | `#E8833A` 눌림 | `#B8650F` 눌림 |
| 불 위 글자 | `#1B0F06` | `#1A1510` |
| 사람 점 | `#FFD79A` ● 크림 | `#1A1510` ● 먹 |

- **밤 테마가 기본·고정**(시스템 라이트 모드 추종 안 함). 낮불은 설정에서 고르는 별도 테마이며 e-ink 외에 밝은 곳 일반 테마로도 그대로 쓴다.
- 사람 = 크림(낮불은 먹) ● / 에이전트 = 파랑 ●(낮불은 ◆). **어떤 화면에서도 바꾸지 않는다.**
- 빨강/초록 신호등 조합 금지. 색만으로 뜻을 전하지 않고 글자를 남긴다.
- 낮불: 그라데이션·반투명·빛남·그림자·애니메이션 0.

## 2. 타이포 · 간격 · 반경

- Pretendard 1벌(OFL)까지. Display 32/600 · Title 22/600 · Body 17/400 · Label 15/500 · Caption 13/400 · 지문·ID JetBrains Mono 14. Dynamic Type: Body↔`.body`, Title↔`.title2`, Caption↔`.footnote`.
- 4pt 그리드(4·8·12·16·24·32) · 반경 S 10 / M 16 / L 24 · 선 밤 1px / 낮불 1.5px · 터치 44 이상.

## 3. 화면 규칙 (1차)

**대화 목록(자리)** — 머리 `hande`(Questrial) + 「오늘 밤, 모닥불에 한데 모여」 · 초대 벨(주황 점) · 순서 편집 · 방 행 = 원형 아이콘(불 세기 1~3단 벡터 불꽃, 숫자 없음) + 이름 + 고정 핀 + 미리보기 + SeatDots(사람 크림·에이전트 파랑) + 시각 + 안 읽음 주황 점 하나(개수 없음) · 꺼진 자리 = 60% 흐림 + 장작 아이콘 + 「불이 꺼진 자리 · 운영자가 닫음」 · 주 버튼 「불 피우기」(+). 이모지 🔥🪵 → 벡터. **목록의 「불지기」 배지(디자인 1b)는 넣지 않는다** — 오너 결정 2026-10-31(iOS #613 · 웹 #540, 목록 배지 없음)이 우선. 에이전트는 SeatDots 의 파란 점으로 보인다.

**대화방** — 제목 아래 SeatDots 요약(「●●● 가족 3 · ● 불지기 공명」) · 남의 말풍선 = 면+선, 꼬리 왼쪽 아래 6 · 내 말풍선 = 불, 꼬리 오른쪽 아래 6 · 에이전트 말풍선 = 파랑 fill 10% + stroke 35%(낮불은 흰 면 + 파랑 점선) · 보낸 이 라벨 = 점 + 이름(에이전트는 「공명 · 불지기」 파랑) · 「공명이 생각하는 중 …」(파랑 점 3개) · 입력창 placeholder 「이야기 나누기…」 · 칩 「사진」「공명 부르기」 · 화면 전체에서 큰 주황 면은 내 말풍선·허락 버튼 2개.

**허락 카드** — 파랑 테두리 1.5px + fill 8% · 머리 「공명이 허락을 구합니다」 · **대상·내용·영향 3줄 고정** → 허락(불)/거절(면) → 진행 중(점 3개 + 「…하는 중」) → 결과(「등록했어요 — …」 + 「다시 보기」). 불확실한 결과는 성공으로 그리지 않는다(「확인 못 했어요」).

## 4. 모닥불 용어 적용표 — 전부 적용(오너 선택), 「처음 보는 조부모」 기준 보조 설명

| 일반어 | 모닥불 용어 | 어디에 · 어떻게 |
|---|---|---|
| 채팅방 | **자리** | 목록 머리·방 설정 제목. 첫 진입 시 1회 「자리 = 대화방」 안내 |
| AI 에이전트 | **불지기** | 배지·이름 옆·허락 카드. 설정 설명문에는 「불지기(AI 에이전트)」 병기 |
| 입력 중 | **타닥타닥** | 말풍선 위 작은 글자 「정인이 타닥타닥…」. 에이전트는 「생각하는 중」 유지 |
| 방 만들기 | **불 피우기** | 주 버튼. 시트 제목 「새 자리 — 불 피우기」 |
| 새 메시지 | **불씨가 튀었어요** | 잠금화면 알림 본문(내용 숨김 기본). 목록 안에서는 주황 점만 |
| 닫힌 방 | **불이 꺼진 자리** | 방 행 보조 글자 + 장작 아이콘 + 60% 흐림. 정지 화면 첫 문장 |
| 알림 끄기 | **잉걸불** | 방 알림 세그먼트 「켜짐 · 잉걸불 · 꺼짐」 — 잉걸불 밑에 「중요한 것만」 |
| 보관 | **불 덮기** | 스와이프·더보기 메뉴. 보관함 제목 「덮어 둔 자리」 |
| 활동량 | **오늘의 불 세기** | 방 행 아이콘 불꽃 1~3단. 숫자·그래프 없음. VoiceOver 「조용함/보통/활발」 |
| 키 생성 중 | **불을 피우는 중…** | 온보딩 기기 등록 대기. 밑줄 「암호 키를 만들고 있어요」 1회 |
| 보내기 · 사진 · 설정 | (은유 없음) | 동작어·시스템 영역은 일반어 고정 |

# 2차-A (2026-10-31) — iOS 전 화면(밤) · 아이콘 정제본

원본: Claude Design 「한데앱 및 웹 디자인 개선 – Hande 2차-A.html」(파일보관함, sha256 `99abaceb…`). 2차-B(낮불 4화면·UI 아이콘 세트·컴포넌트 상태표)는 별도.
1차 규칙 유지. 추가 규칙: 설명은 **1줄 + 「자세히」**, 성공 표시는 글자로만(체크 배지 없음), 숫자·카운트다운 없음.

## A1. 새 기기 승인(기존 기기 쪽) — 「대충 승인」을 막는 세 겹
1. 지문은 새 기기 등록 화면과 **같은 세로 1열·같은 번호 순서**(행 42pt, 번호 Caption 13, 값 모노 19, 표시 원 22pt).
2. 행마다 직접 눌러 표시해야 하고 전부 표시되기 전까지 「승인」은 꺼짐(꺼진 문구 「n개를 모두 맞춰 보세요」, 면 ember 18%·글자 45%).
3. 「지문이 다르면 승인하지 말고 운영자에게 알려 주세요」 경고(선 1.5px warn 55%·면 7%)는 항상, 「다릅니다」(46pt 위험)는 승인 바로 아래.
- 기기 카드: 기기 ID 모노 18 · 종류·요청 시각·**만료 시각**(카운트다운 없음). 결과: 「○○를 승인했어요 — 이 기기가 있는 자리에 자동으로 초대합니다」 / 「승인하지 않았어요」 + 진단 기록 복사.
- 구현 주의: 실제 지문은 7단어가 아니라 **hex 묶음**(`SelfService.fingerprintGroups`) — 묶음 수만큼 행을 만들고 같은 게이트를 건다.

## A2. 온보딩 4단계 (상단 3px 진행 막대 4칸, ember)
① 서버 찾기: `hande` 워드마크 30 + 제목 28/600 + **「한데에는 회원가입이 없습니다 — 가족 운영자가 등록합니다.」 카드(ember 8%·선 35%)** + 주소 입력(모노, 52pt 반경 14) + 1줄 안내 + 「자세히」 → 찾으면 서버 카드(자리 점 + 이름 + 모노 주소 + 「찾았어요」) + 「이 서버로 계속」. 오류 = 카드 자리에 warn 선 + 1줄.
② 이름: 「한 번 정하면 바꿀 수 없어요. 자세히」(접힘: 형식 규칙·이유). 형식 오류 = 칸 선 warn + 1줄.
③ Google 로그인: 주 버튼은 **크림 면(#F3E6D3) + 진한 글자**(화면 할 일 하나). 운영자용 「직접 입력」은 맨 아래 접힌 행.
④ 이 기기 등록 — 상태 3: 「불을 피우는 중…」(자리 점 4개 순차 밝아짐, 「암호 키를 만들고 있어요」) → 지문 1열 7행 + 「운영자 승인을 기다리는 중」(점 3개, 기술값 403… 제거 → 진단 기록) + 「등록 정보 공유」 → 「불 곁으로 오세요 — 등록됐어요. 이제 가족 자리에 앉을 수 있습니다.」 + 「자리로 가기」.

## A3. 오프닝 · 목록 빈 상태 · 순서 편집
- 오프닝: 일러스트 위 76% + 아래 24% 밤하늘로 녹임, 워드마크 52, 하단 점 3개 = **준비 중 표시**(크림 2 + 파랑 1 순차, reduce motion이면 고정).
- 빈 상태: 꺼진 장작 + 불씨 1점 + 자리 점 2(흐림) 그림(불 그림은 여기만), 「아직 피운 모닥불이 없습니다 / 운영자가 초대하면 여기에 자리가 생겨요.」, 초대 있으면 안내 카드(숫자 대신 「있어요」), 순서 편집 버튼은 0개일 때 숨김.
- 순서 편집: 머리 「자리 순서」 + ember 「완료」, 「끌어서 순서를 바꾸세요. 이 기기에만 저장돼요.」, 행 = ≡ + 이름 + 고정 핀(켜짐 ember 16%) + ▲▼(각 40pt). 불 세기·미리보기·안 읽음 숨김. 꺼진 자리 60% + 고정 불가.

## A4. 대화방 상태
보내는 중(불 면 + Caption 12) · 연결되면 보냅니다(75% + 시계 12) · **전송 안 됨 = 면 ember 22% + 선 1.5px warn, 글자 크림, 아래 「전송 안 됨 · 다시 보내기」(#F08A70)** · 첨부 보내는 중 = 미리보기 200×150 + 「사진·파일 보내는 중」 + 진행선 3px(숫자 없음) · 새 메시지 점프 = 입력창 위 10pt 높이 36 알약(면 #1C2136, ember 점 + 「새 메시지 ↓」) · 타닥타닥 = 크림 점 6 + 「정인이 타닥타닥…」 · 배너 = 연결 중(면 7%) / 릴레이에 닿지 않음(warn 10%/선 45%, 「릴레이에 닿지 않아요 — 연결되면 보낼게요」) 반경 12.

## A5. 설정(순서 = 자주 → 드물게 → 위험) · 알림함
서버(이름·모노 주소·「바꾸기」) → **화면**(밤/낮불 세그먼트 + 힌트) → 알림(새 메시지 알림·잠금화면 미리보기; 「항상」일 때만 경고 상자 + 설정 열기/나중에) → 이 기기(기기 ID + 복사 · 「운영자용 정보」 접힘: 로비 키·epoch·릴레이 모노 블록) → 기기 관리(활성 / 폐기 링크 / 폐기됨 55%) → 계정(로그아웃 1줄 설명) → **위험 구역**(선 warn 50% 상자, 「이 기기 지우기」 하나만) → 정보(정책 2 링크·버전 모노).
알림함: 카드 3상태 — 기본(수락 주 44pt / 무시 보조) · 수락하는 중(크림 점 3) · 실패(선 warn 45% + 사람 말 1줄 「자동 수락이 두 번 안 됐어요 — 키는 그대로라 다시 시도할 수 있어요」 + 다시 시도/무시). 오른쪽 위 「기록 복사」(토스트 「복사했어요」). 빈 상태 = 흐린 자리 점 3 + 「새 알림이 없어요」.

## A6. 정지 · 꺼진 자리
- 정지된 기기: **radial 번짐 없는 단색 밤하늘** + 꺼진 재 점 3 + 「이 기기의 대화가 멈췄어요」 + 사유별 1문장 + 「운영자에게 알려 주세요…」 + 「진단 기록 복사」(주)/「설정 열기」(보조). ⛔ 이모지 제거.
- 꺼진 자리: 제목 아래 「불이 꺼진 자리」, 말풍선 60%, **입력창 자리를 안내 상자로 교체**(장작 아이콘 + 「운영자가 이 자리를 닫았어요」 + 1줄 + 「덮어 두기」).

- 꺼진 자리: 흐림(투명도 금지) 대신 **점선 테두리 1.5 + 회색 `#8A8178` 글자 + 장작**.

- 「승인」 꺼짐: 종이 면 + 1.5 **점선** `#8A8178` + 회색 글자 → 켜짐 `#D97A1E` 면 + 먹 선. 비활성은 모두 투명도 대신 **점선 + 회색**.
