# 한데 디자인 시스템 — 1차 (2026-10-31)

원본: Claude Design 「한데앱 및 웹 디자인 개선 – Hande 1차.html」(파일보관함, sha256 `335c9283…`) · 의뢰서 `hande-app-design-brief-20261031.md` · 토큰 정본 [`hande-tokens.json`](hande-tokens.json).

1차 범위 = **토큰 정리(밤·낮불) + 대화 목록(자리) + 대화방·허락 카드(밤·낮불) + 모닥불 용어 적용표**. 2차(전 화면·아이콘), 3차(Android 전 화면·스토어), 4차(웹)는 별도.

- 낮불: 그라데이션·반투명·빛남·그림자·애니메이션 0.

## 2. 타이포 · 간격 · 반경

- Pretendard 1벌(OFL)까지. Display 32/600 · Title 22/600 · Body 17/400 · Label 15/500 · Caption 13/400 · 지문·ID JetBrains Mono 14. Dynamic Type: Body↔`.body`, Title↔`.title2`, Caption↔`.footnote`.
- 4pt 그리드(4·8·12·16·24·32) · 반경 S 10 / M 16 / L 24 · 선 밤 1px / 낮불 1.5px · 터치 44 이상.

## 3. 화면 규칙 (1차)

**대화 목록(자리)** — 머리 `hande`(Questrial) + 「오늘 밤, 모닥불에 한데 모여」 · 초대 벨(주황 점) · 순서 편집 · 방 행 = 원형 아이콘(불 세기 1~3단 벡터 불꽃, 숫자 없음) + 이름 + 고정 핀 + 미리보기 + SeatDots(사람 크림·에이전트 파랑) + 시각 + 안 읽음 주황 점 하나(개수 없음) · 꺼진 자리 = 60% 흐림 + 장작 아이콘 + 「불이 꺼진 자리 · 운영자가 닫음」 · 주 버튼 「불 피우기」(+). 이모지 🔥🪵 → 벡터. **목록의 「불지기」 배지(디자인 1b)는 넣지 않는다** — 오너 결정 2026-10-31(iOS #613 · 웹 #540, 목록 배지 없음)이 우선. 에이전트는 SeatDots 의 파란 점으로 보인다.

**대화방** — 제목 아래 SeatDots 요약(「●●● 가족 3 · ● 불지기 공명」) · 남의 말풍선 = 면+선, 꼬리 왼쪽 아래 6 · 내 말풍선 = 불, 꼬리 오른쪽 아래 6 · 에이전트 말풍선 = 파랑 fill 10% + stroke 35%(낮불은 흰 면 + 파랑 점선) · 보낸 이 라벨 = 점 + 이름(에이전트는 「공명 · 불지기」 파랑) · 「공명이 생각하는 중 …」(파랑 점 3개) · 입력창 placeholder 「이야기 나누기…」 · 칩 「사진」「공명 부르기」 · 화면 전체에서 큰 주황 면은 내 말풍선·허락 버튼 2개.

**허락 카드** — 파랑 테두리 1.5px + fill 8% · 머리 「공명이 허락을 구합니다」 · **대상·내용·영향 3줄 고정** → 허락(불)/거절(면) → 진행 중(점 3개 + 「…하는 중」) → 결과(「등록했어요 — …」 + 「다시 보기」). 불확실한 결과는 성공으로 그리지 않는다(「확인 못 했어요」).

## 4. 모닥불 용어 적용표 — 전부 적용(오너 선택), 「처음 보는 조부모」 기준 보조 설명

| 일반어 | 모닥불 용어 | 어디에 · 어떻게 |
|---|---|---|
| 채팅방 | **자리** | 목록 머리·방 설정 제목. 첫 진입 시 1회 「자리 = 대화방」 안내 |
| AI 에이전트 | **불지기** | 배지·이름 옆·허락 카드. 설정 설명문에는 「불지기(AI 에이전트)」 병기 |
| 입력 중 | **타닥타닥** | 말풍선 위 작은 글자 「정인이 타닥타닥…」. 에이전트는 「생각하는 중」 유지 |
| 방 만들기 | **불 피우기** | 주 버튼. 시트 제목 「새 자리 — 불 피우기」 |
| 새 메시지 | **불씨가 튀었어요** | 잠금화면 알림 본문(내용 숨김 기본). 목록 안에서는 주황 점만 |
| 닫힌 방 | **불이 꺼진 자리** | 방 행 보조 글자 + 장작 아이콘 + 60% 흐림. 정지 화면 첫 문장 |
| 알림 끄기 | **잉걸불** | 방 알림 세그먼트 「켜짐 · 잉걸불 · 꺼짐」 — 잉걸불 밑에 「중요한 것만」 |
| 보관 | **불 덮기** | 스와이프·더보기 메뉴. 보관함 제목 「덮어 둔 자리」 |
| 활동량 | **오늘의 불 세기** | 방 행 아이콘 불꽃 1~3단. 숫자·그래프 없음. VoiceOver 「조용함/보통/활발」 |
| 키 생성 중 | **불을 피우는 중…** | 온보딩 기기 등록 대기. 밑줄 「암호 키를 만들고 있어요」 1회 |
| 보내기 · 사진 · 설정 | (은유 없음) | 동작어·시스템 영역은 일반어 고정 |

원칙: 은유는 **제목·버튼**에, 일반어는 **첫 노출 보조 설명(1회)** 과 **시스템 영역**(OS 알림 설정, 권한 다이얼로그, 오류)에.
