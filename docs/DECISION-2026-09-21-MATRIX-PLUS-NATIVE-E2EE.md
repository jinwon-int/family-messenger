# 결정 기록 — 2026-09-21: Matrix는 운영 전달층으로 유지하고, 독자 E2EE를 병행 개발한다 ("E")

**상태:** 오너 결정(2026-09-21). 방향 결정이며 코드 해동·CI 재가동·운영 전환을 뜻하지 않는다.
**대체하는 문장:** [결정 D](DECISION-2026-09-13-MATRIX-CRYPTO-STACK.md)의 「네이티브 MLS는 전달층에서 폐기」·[ROADMAP](ROADMAP.md) 5단계 「1~4단계 전에는 전달층 자체화를 판단하지 않는다」.
**유지하는 것:** 결정 D의 **운영 전달·암호화는 Matrix 스택**. 화면·AI 층은 직접. [VISION.md](VISION.md) 불변. [NATIVE-E2EE.md](NATIVE-E2EE.md)의 위협 모델·기기 정책·수용 기준은 독자 트랙의 인수검사 기준으로 다시 쓴다.
**추적:** [이슈 #92](https://github.com/jinwon-int/family-messenger/issues/92). 문서와 어긋나면 #92가 우선한다.

## 결정

가족이 Matrix 패밀리챗을 사용해 본 뒤의 결론이다.

| 층 | 결정 |
|---|---|
| 지금 가족이 쓰는 전달·암호화 | **Matrix 유지.** Tuwunel + `matrix-sdk-crypto` / `matrix-js-sdk`. 운영 경로를 독자 스택으로 바꾸지 않는다. |
| 독자 E2EE (OpenMLS·자체 전송) | **개발 동결 해제. Matrix와 병행.** 합성 실험에서 멈춘 지점부터 이어서 만든다. |
| 독자 스택의 운영 투입 | **별도 오너 결정 전까지 금지.** 합성 시험 통과만으로 가족 키·실대화를 올리지 않는다. |
| Matrix 제품 단계(2~4) | **계속 진행.** 독자 트랙이 이 단계를 막지 않는다. 1단계 숫자 게이트(실대화 100건)는 Matrix 제품 경로에만 적용한다. |

결정 D를 뒤집는 것이 아니다. D는 「지금 가족이 쓰려면 Matrix로 전달층을 산다」였고, 그 선택은 유지한다. 바꾸는 것은 「자체 E2EE는 4단계 끝날 때까지 손대지 않는다」는 동결이다.

## 왜 지금 여는가

결정 D 당시 근거는 「쓰는 사람이 없는 배포 위에 암호학 인프라를 쌓고 있다」·「독자 E2EE가 완성되기 전에는 사람 사용이 불가능해 첫 가족 메시지가 5~6개월 뒤」였다. Matrix를 운영 전달층으로 둔 뒤에는 그 막힘이 사라졌다. 가족이 이미 Matrix로 대화하므로, 독자 트랙을 다시 켜도 첫 가족 메시지를 미루지 않는다.

5단계에서 미루기로 한 재검토를 오너가 앞당긴 것이다. 1~4단계 KPI를 「자체화 여부를 판단할 자격」으로 쓰지는 않는다. 그 KPI는 Matrix 제품 깊이를 막는 장치로 남긴다.

## 병행 규칙

1. **두 트랙은 저장소에서 섞지 않는다.** Matrix 운영 경로(`deploy/tuwunel/`, `web/`, `scripts/fleet_matrix.py`)를 독자 MLS 스키마·실험 CI에 묶지 않는다. 독자 코드는 보존 브랜치 [`archive-frozen-20260917`](https://github.com/jinwon-int/family-messenger/tree/archive-frozen-20260917/archive)의 `archive/native-mls/`·`archive/experiments/`에서 이어 가며, main으로의 해동은 **별도 PR**이다. 이 문서는 해동을 수행하지 않는다.
2. **옛 `mls-experiment.yml` 팬아웃을 그대로 켜지 않는다.** 결정 D 당시 1 job/35분 → 16 job/535분으로 재팽창한 이력이 있다. 독자 트랙 CI는 예산 상한을 명시한 새 워크플로만 허용한다. 상한 없는 재가동은 거부한다.
3. **독자 트랙 게이트는 [NATIVE-E2EE.md](NATIVE-E2EE.md) 수용 순서다.** 이미 끝난 합성 구간(브라우저 왕복·스테이징 저장·합성 배달·합성 UI)을 다시 자랑하지 않고, 남은 사람 사용 게이트(기기 신뢰·복구·내구성·실기기)부터 이어 간다. 사람 키·계정·운영 호스트는 이 트랙의 기본 범위가 아니다.
4. **복호화 실패를 평문으로 숨기지 않는다. 복구 키를 서버가 수집하지 않는다.** 결정 D와 같다.
5. **전달층을 독자 스택으로 바꾸는 컷오버**는 이 결정의 범위가 아니다. NATIVE-E2EE 사람 사용 게이트를 통과한 뒤 오너가 따로 고른다.

## 이 결정이 하지 않는 것

- 아카이브 파일을 main에 되돌리지 않는다.
- `mls-experiment.yml`을 재활성화하지 않는다.
- 운영 홈서버·웹·봇을 재시작하거나 설정을 바꾸지 않는다.
- 1단계 게이트(가족 실대화 100건)를 통과로 표기하지 않는다. 오너가 Matrix를 써 본 것과 숫자 게이트는 별개다.
- 음성·영상 통화는 계속 범위 밖이다.
