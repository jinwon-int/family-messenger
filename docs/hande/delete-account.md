# 한데(Hande) 계정 및 데이터 삭제 안내 — 초안(DRAFT, #584 PR 4 에서 확정)

> **상태: 초안.** Google Play 「계정 삭제 요청」 URL · App Store 와 공용. 앱 설정 화면의 「계정 및 데이터 삭제」 링크가 이 페이지를 연다. 연락처·처리 기한은 PR 4 에서 확정한다.

## 한데의 「계정」이란
한데에는 아이디·비밀번호 계정이 없다. 「계정」은 두 가지의 조합이다.
1. **로그인 신원** — 가족 운영자가 허용한 Google 계정(Cloudflare Access 로그인). 허용 목록은 운영자가 관리한다.
2. **기기 기록** — 각 기기가 처음 설정에서 만든 기기 ID(`<이름>-android-…` / `<이름>-iphone-…`)와 서명 공개키·지문·상태(활성/폐기)·로그인 신원(`subject`) 이 적힌 릴레이의 기기 정책 체인.

대화 내용은 종단간 암호화되어 서버에 **암호문으로만** 있고, 복호화된 기록은 각 기기 안에만 있다.

## 1. 지금 바로 — 이 기기의 자료 지우기(앱 안)
앱 → **설정**(대화방 목록·등록 대기·로그인 화면 오른쪽 위) → **「이 기기 지우기」** → 확인.
지워지는 것: 이 기기의 암호화 키·그룹 상태, 복호화된 대화 기록(`messages.db`), 로그인 세션 값, 설정(서버·이름·읽음 위치), 기기 ID. 앱은 처음 설정으로 돌아가고 다음 등록은 **새 기기 ID** 로 한다(옛 ID 는 다시 쓸 수 없다). 되돌릴 수 없다. 앱 삭제도 같은 효과다.

이 기기 지우기로는 **서버의 기기 기록이 바뀌지 않는다**(기기 기록은 다른 기기·운영자의 승인으로만 바뀌는 변조 방지 체인이라 앱 혼자 지울 권한이 없다). 서버 쪽은 아래 2 를 요청한다.

## 2. 서버 쪽 — 기기 폐기 · 대화방 데이터 삭제 · 로그인 허용 해제(요청)
**support@rnmaru.com** 으로(또는 가족 운영자에게 직접) 다음을 적어 보낸다.
- 로그인에 쓴 Google 계정(이메일)
- 요청 범위(해당하는 것 전부):
  - [ ] 기기 폐기 — 기기 ID(앱 설정 화면·「내 기기」에 표시) 또는 「내 기기 전부」
  - [ ] 내가 참여한 대화방의 서버 데이터(암호문·메타데이터·읽음 위치) 삭제
  - [ ] 로그인 허용 목록에서 제외(더는 한데에 로그인하지 않음)

운영자가 하는 일(절차는 운영 문서 `docs/DEVICE-LIFECYCLE.md` · `docs/NATIVE-RELAY-OPERATIONS.md`):
1. 요청자가 그 Google 계정의 주인인지 확인(해당 계정에서 보낸 메일, 또는 가족 운영자가 직접 확인).
2. 기기 폐기(체인에 `revoke` 기록) — 그 기기로는 어떤 요청도 할 수 없게 된다. 폐기는 불변 기록이라 기기 식별자·공개키·로그인 신원은 「폐기됨」 상태로 체인에 남는다(변조 방지 목적, 그 외 용도 없음).
3. 대화방 정리 — 참여자 전원이 동의한 대화방은 닫고(`closed`) 데이터를 삭제(`-reset-room`). 다른 가족이 계속 쓰는 대화방은 요청자의 기기를 멤버에서 제거하고, 요청자의 암호문·읽음 위치는 보존 기한(최대 30일, 첨부 60일)에 따라 자동 정리된다.
4. 로그인 허용 목록(Cloudflare Access 정책)에서 제외.
5. 처리 결과 회신 — 접수 후 **7일 이내**(초안 기한).

## 3. 삭제 뒤 남는 것
- 기기 정책 체인의 「폐기됨」 기록(기기 ID·공개키·지문·로그인 신원·폐기 시각) — 변조 방지 불변 기록.
- 다른 가족의 기기에 이미 전달된 메시지(각자의 기기 안에만 있고 서버에는 없다).
- 서버 로그(기기 ID·요청 경로, 내용 없음)는 운영자 로그 보존 기간이 지나면 지워진다.
