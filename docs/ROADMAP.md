# 개발 순서

[제품 비전](VISION.md)의 첫 목표는 가족방 하나에서 가족과 AI 한 명이 함께 대화하고,
기억을 관리하고, 작은 일을 끝내는 경험이다. 아래는 개발·인수검사 순서이며 완료 목록이 아니다.

## 1. 가족과 AI가 함께 대화

- 가족 계정·개인방·가족방, 사람과 AI를 구별하는 참여자 표시
- AI 한 명의 명시적 호출과 응답, 참여 전에 열람·제공업체 전달 범위 안내
- 방별 접근 권한, 텍스트·사진·영상·일반 파일, 재접속과 중복 방지
- 쉬운 한국어와 휴대폰 화면

## 2. 확인받고 기억하고 실행

- 기억 저장 확인, 출처·개인/가족 공유 범위 표시, 조회·수정·삭제
- 일정·할 일 정리와 외부 실행 전 대상·내용 확인
- 승인·거절·취소·진행·결과, 불확실한 작업의 자동 재실행 금지
- 개인 대화를 가족방에 공유하기 전 당사자 확인

## 3. 실제 가족 사용을 위한 검증

- 실제 두 기기 암호화·키 복구·첨부 열람·재연결
- 모바일 설치·알림과 잠금 화면 내용 노출 범위
- 별도 환경 백업 복원, 용량 경보, 오류·복구 안내
- 기존 서비스를 보존한 상태에서 새 구현의 인수검사와 전환 계획 검증

## 4. 여러 AI 에이전트로 확장

- 에이전트별 신원·역할·대화 및 실행 권한
- 명시적 지목, 동시 실행 상한, 중복 응답·작업 방지
- 노드 단절·취소·복구와 제공업체별 동작 검증
- [에이전트 연결 설계](FLEET-BRIDGE.md)와 [자체 시스템 계약](OWN-SYSTEM.md) 재사용

음성·영상 통화는 현재 범위 밖이다. 기존 대화 기록 이관은 별도 동의와 대상 선정 후 진행한다.
Matrix 배포 구성과 자체 서버 시험판은 구별하며, 공개 저장소 전환은 운영 데이터 이전을 수행하지 않는다.
