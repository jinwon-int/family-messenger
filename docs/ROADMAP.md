# 개발 순서

핵심 범위는 개인·단체 텍스트 메시지와 사진·영상·일반 파일 송수신입니다.
음성·영상 통화와 이를 위한 TURN/LiveKit 구성은 개발 범위에서 제외합니다.

## 1. 실행 가능한 기반 — 이번 저장소

- 버전 고정 Matrix/PostgreSQL/Element 구성
- 가족 계정 발급, 공개 가입 차단, 초대방·기본 암호화
- 한국어 시작 화면, 실제 서버 API 검사와 CI
- 기존 Telegram 및 seo web bridge와 분리

## 2. 가족 시험 배포

- 운영 서버: **육손(yukson)** — 2026-09-08 운영자 확정. 메시지 DB와 사진·영상·파일을 같은 서버에 배치한다.
- 서서는 개발·시험용으로 유지한다. 육손 HTTPS 운영 배포·관리자 계정·비공개 가족방·시간별 용량 점검·일일 암호화 백업은 2026-09-08 완료했다.
- 공명 백업 공간과 미디어 보관량을 함께 점검한다. 외부 경보 전달과 실제 가족 기기 인수검사는 후속 진행한다.
- 운영 주소·설치 신원 결정, HTTPS 연결
- 두 기기에서 실제 암호화 텍스트 메시지 송수신·키 복구 검증
- 사진 열람, 영상 첨부·수신 기기 재생, 일반 파일 다운로드 검증
- 현재 업로드 상한 50M과 초과 안내, 실패 후 재시도·중복 여부 확인
- 가족 계정과 비공개 공용방 생성, 초대 흐름 단순화
- 백업을 별도 서버에 복원하는 절차 자동화·검증

## 3. 휴대폰 사용성

- iOS/Android 웹 설치 가능성과 백그라운드 제한 실측
- Element X를 쓸 경우 MAS/OIDC와 로그인·로그아웃·복구 검증
- 푸시 경로와 알림 본문 노출 여부 결정 및 테스트
- 필요하면 자체 모바일 앱: 기존 Matrix SDK 재사용

## 4. 가족 기능

- 사진 모아보기, 가족 공지, 일정·할 일
- AI 가족 에이전트: 가족 대화와 에이전트 접근 범위를 명시적으로 구분
- Telegram 기록 이관은 별도 동의와 대상 선정 후 선택적으로 진행
